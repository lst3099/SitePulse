# 当前实现快照

**项目**：SitePulse  
**日期**：2026-08-26  
**技术栈**：React 19、Vite、Ant Design、dayjs、Vitest

## 已实现的 PC 端模块

当前 `src/pages/` 已包含以下模块页面：

- 工作台、项目列表、项目详情。
- 人员、设备、考勤、告警、报表。
- 健康报告属于人员资料；年龄权限和特殊授权属于项目详情的项目人员。
- 工器具、基础数据、用户权限、操作日志。
- 项目详情已支持“绑定已登记设备时选择出入口 → 同步项目人员”的门禁原型流程；全局设备页面保留物理设备登记和状态查看。

考勤表只依据当天最早、最晚有效打卡时间判断迟到和早退；门禁记录页面单独展示设备、出入口、进出方向和是否开门。

## 已实现的移动端页面

当前 `src/pages/mobile/` 和 `MobileShell` 已包含：

- 我的考勤：`mobileAttendance`
- 考勤概览：`mobileOverview`
- 项目切换：`mobileProjects`
- 人脸同步状态：`mobileFaceSync`
- 个人信息：`mobileProfile`

移动端导航没有扫码打卡路由；`App.jsx` 的移动端路由和 `MOBILE_VIEW_KEYS` 以这五个页面为当前实现事实。

## 已覆盖的工程验证

- `src/` 中存在领域逻辑测试、页面测试、移动端任务复核和质量复核测试。
- 当前仓库为 Vite 项目，主要命令为 `pnpm dev`、`pnpm build`、`pnpm test` 和 `pnpm test:run`。

## 与业务文档的差异点

- 业务文档曾写“移动端暂定保留我的考勤、项目切换、个人信息和密码修改”，代码还实现了考勤概览和人脸同步状态。
- `ProfilePage` 提供查看人脸同步状态入口；该入口是否面向普通打卡人员开放，仍需产品确认。
- 代码和文档都已移除移动端扫码打卡，但旧资料中的历史描述仍保留在 `workspace/source-materials/`，不可作为当前功能依据。
