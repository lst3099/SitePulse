# 方案与原型 MECE 对照表

## 一、核对说明

- 核对日期：2026-08-26
- 方案基线：`workspace/source-materials/系统建设方案.md`，V0.2（当前业务方案与验收核对版）。
- 原型范围：当前仓库 `src/` 下的 React/Vite 原型及其测试，不把历史源码、旧系统附件或未接入的服务视为当前原型已实现。
- 辅助事实：`workspace/current-implementation.md`、`workspace/release-scope.md`、`context/product-overview.md`、`context/system-architecture.md`。
- 核对方式：按“功能模块、页面结构、角色权限、数据对象、业务流程、边界条件、非功能要求”七个维度拆分，再将每一项映射到方案条目和原型证据。
- 本表的“匹配”只表示当前原型在界面或前端逻辑层有对应表现，不表示后端、数据库、真实设备接入或生产环境已经完成。

## 三、总体结论

1. 页面骨架和主要业务演示已经覆盖人员、项目、设备、门禁记录、考勤、告警、报表和工器具等核心模块。
2. 当前原型仍是前端本地演示：`src/App.jsx:66-97` 以 React state 和 mock 数据维护数据，不能据此确认数据库持久化、真实设备接入、服务重启后数据保存和并发一致性。
3. 已确认的页面归属基本匹配：独立“健康证与年龄限制”入口已从菜单和应用路由移除；特殊授权已放入“项目详情 → 项目人员”。
4. 本轮已处理的匹配事项：
   - 当前原型已提供工具按周期检查与提醒，默认实现为每月；本版以“需要定期检查”为准，不固化三个月默认周期，具体周期结合实际使用情况确定，见 `src/domain/tools.js:14-22` 和 `src/data/mockData.js:163-169`。
   - 考勤已按当天最早、最晚有效打卡判断迟到、早退和正常，不再根据进出门方向推断；门禁记录页单独展示出入口、方向和是否开门，并支持从考勤详情带项目、人员、日期筛选跳转。
   - 项目已支持配置年龄阈值和预警天数，默认值为 60 岁/30 天，入口位于项目编辑和项目详情。
   - `workspace/current-implementation.md:9-14` 已同步为人员管理中的健康资料、项目人员中的年龄权限/特殊授权，避免实现说明文档漂移。
5. 方案正文中的“特殊审批”已统一为“特殊授权”，当前未发现旧称残留。
